# Jujutsu Text Battle 2

Текстовая игра по вселенной **Jujutsu Kaisen** на Python. Открывайте кейсы,
собирайте магов и проклятия шести рангов редкости и сражайтесь против проклятий
в пошаговых боях.

## Возможности

- **Открытие кейсов (гача)** — выбивайте персонажей с разными шансами по рангам.
- **6 рангов редкости**:
  - 5-й ранг (самый частый)
  - 4-й ранг
  - 3-й ранг
  - 2-й ранг
  - 1-й ранг
  - Особый ранг (самый редкий)
- **Коллекция** персонажей с возможностью выбрать активного бойца.
- **Продажа дубликатов** за проклятые монеты.
- **Пошаговые сражения**: обычные атаки, проклятые техники (накопление энергии),
  защита, криты и побег.
- **Валюта** (проклятые монеты): зарабатывается в боях, тратится на кейсы.
- **Сохранение и загрузка** прогресса в `savegame.json`.

## Запуск

Требуется Python 3.8+ (рекомендуется 3.10+).

**Графическая версия (рекомендуется) — оконный интерфейс на Tkinter:**

```bash
python game_gui.py
```

Tkinter входит в стандартную поставку Python, ставить ничего не нужно.

**Консольная версия (по желанию):**

```bash
python game.py
```

> Windows: для корректного отображения кириллицы в консольной версии запускайте
> её в обычном окне терминала (PowerShell/Windows Terminal).

## Структура проекта

- `game_gui.py` — **графическая версия** (Tkinter): окна, анимация кейсов, бои с полосами HP.
- `game.py` — консольная версия игрового движка.
- `characters.py` — общая база персонажей, ранги, шансы и цвета.
- `savegame.json` — файл сохранения (создаётся автоматически, общий для обеих версий).

## Как играть

1. Введите имя мага — получите стартовые 300 монет и бесплатный кейс.
2. В **магазине** открывайте кейсы (100 монет за штуку).
3. В **коллекции** выбирайте активного бойца и продавайте лишние дубликаты.
4. Идите **в бой** против проклятий, чтобы зарабатывать монеты.
5. Чем выше ранг противника — тем больше награда, но и сложнее бой.

Удачи, маг!
